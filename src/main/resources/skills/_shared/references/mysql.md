# MySQL

## Index
- Vi sao dung B+Tree ma khong dung B-Tree hay hash
- Clustered index vs secondary index, hien tuong quay lai bang (table lookup)
- Composite index va nguyen tac tien to trai nhat
- Cac truong hop index mat tac dung: dung ham len cot, ep kieu ngam, LIKE dau %
- Covering index giup gi

## Transaction va khoa
- ACID va bon muc co lap
- Read uncommitted / committed / repeatable read / serializable gay ra van de gi
- MVCC: read view, undo log, snapshot read vs current read
- Row lock, gap lock, next-key lock; nguyen nhan deadlock

## Toi uu
- Doc EXPLAIN: type, key, rows, Extra
- Slow query log dung the nao
- Phan trang sau (deep pagination) cham vi sao, cach xu ly
